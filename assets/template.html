Three options for one system

All three share the same foundations: one brand palette, a type scale that starts at a 16px body, spacing on a 4px unit, and controls that grow on touch screens. They differ in three things: shape, depth, and where the brand colour shows up. Pick any option and the whole page redraws in it.

Colour

One palette in all three options; what changes is the role each colour plays. Steps 20 to 80% are tints of each base colour, and an 8% step is added for light washes.

Primary palette

brand-accent is not usable as text on white (2.77:1); its text-safe stand-in is accent-ink #0A7CAF (4.65:1).

Secondary palette

In options A and B these are for status only. In option C they also tell categories apart, one colour per category.

Status colours

Each status has three values: a light wash, an ink that reaches 4.5:1 on that wash, and a dot. Green, blue and yellow come from the secondary palette; red is added because the palette has no error colour.

A paragraph at real length

The Website relaunch project brings marketing, design and engineering onto one plan for six weeks. Each team owns its own board, and a weekly review keeps the scope in check. When 80% of the tasks are done and the final review passes, the project moves to billing and an invoice goes to the client.

Maximum measure 62 characters; line height 1.62 (26px for 16px text).

Space and grid

Every gap is a multiple of 4px. Related items sit close, groups sit apart, and the space above a heading is larger than the space below it.

Breakpoints — Bootstrap-style (demo)

Mobile first: the base styles serve the small screen, and each breakpoint adds what a larger screen needs with min-width. A 12-column grid, 24px gutters on desktop and 16px on phones, and a 1320px maximum content width.

Control heights

Three sizes only. Each grows on touch screens, so no button or field on a phone is shorter than 40px.

Shape, depth and motion

This section differs most between the options. The values shown are for the option selected at the top.

Card · shadow 1
Inner element · shadow 2
Popover · pop shadow
Button

Each shadow level has a vertical offset and a soft spread, tinted with brand-dark rather than black. Motion starts fast and eases out (cubic-bezier(.16,1,.3,1)) over 200ms. Content reveals on page load happen once and take 600ms. All of it stops when the user asks the system for reduced motion.

Icons and focus

One outline icon set at a 1.6 stroke, in three sizes: 16, 20 and 24. Directional icons (arrows, back, breadcrumb separators) mirror with text direction; the rest never do.

Focus ring

Shown for keyboard navigation only. brand-accent on white is 2.77:1, under the 3:1 that UI components need, so the ring is focus-accent #0D96D4 (3.32:1) in options A and C, and brand-deep (11.42:1) in option B.

Buttons

One primary button per region of the page; the secondary button for what comes after it. A button label is a clear verb, such as "Create project" rather than "Submit".

States and icons

The icon goes before the label; an arrow that shows direction goes after it. An icon-only button is square at its size's height and carries an aria-label. While loading, a spinner replaces the label and the button keeps its width.

Fields

The label always sits above the field, never inside it. Mark required fields with an asterisk when most fields are optional, and optional ones with "Optional" when most are required. An error message says what is wrong and how to fix it.

Open decisions

The first decision is the option. The rest need an answer from the product owner; this page does not assume them.

  1. Which option — or which mix?

    Options can be combined, for example B's shape with C's colour. Pick one source per layer (shape, depth, colour) and never blend two options' values inside the same layer.

  2. Is there a web licence for the brand font?

    If not, the current fallback stays; both fonts can be compared with the switch at the top. The scale and sizes do not change with the font.

  3. Does a compliance standard apply?

    If the product falls under an accessibility or design standard, name it and the version in force; it decides how close to option B the result must be.

  4. Move the body text to 16px?

    Larger body text is easier to read; users will notice the change first in dense tables. Confirm before the scale is applied.

  5. Which error colour?

    The palette has no error colour, so this page uses #B42318 (6.05:1 on its wash, 6.57:1 for white text on it). Confirm it or supply the brand's own.
